Flex Sensor Trainer Kit

Web statis ringan untuk latihan mapping flex sensor ke servo, arm gripper, grafik realtime, dan output suara laptop dalam satu halaman trainer kit.

Buka Trainer Kit
01

Servo

Flex A mengontrol sudut servo 0-180 derajat saat bagan servo ON.

02

Arm Gripper

Flex A menggeser arm, Flex B membuka dan menutup gripper.

03

Grafik + Audio

Grafik flex berjalan realtime dan threshold memicu output suara.
