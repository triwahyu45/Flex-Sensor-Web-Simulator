# Flex Sensor Web Simulator

An interactive web-based simulator for prototyping and visualizing **Flex Sensor** analog inputs connected to a virtual **ESP32** microcontroller.

🚀 **[Buka Live Web Simulator di sini!](https://triwahyu45.github.io/Flex-Sensor-Web-Simulator/)**

---

## 🌟 Features

*   **Interactive Flexing**: Drag the slider to simulate bending/flexing the sensor.
*   **Virtual ESP32 Console**: Displays live ADC (Analog-to-Digital Converter) raw readings and mapped output values.
*   **Dynamic Visuals**: The sensor graphical representation bends in real-time as you drag the controller.
*   **Code Exporter**: Provides ready-to-use ESP32 Arduino code for flex sensors.

---

## 📂 File Map

*   `simulator.html` - The main flex simulation window with dynamic bending graphics.
*   `virtual-esp32.html` - Interactive screen showing ESP32 mock pin connection and ADC telemetry console.
*   `index.html` - Home portal linking the tools.
*   `assets/` - UI stylesheets and vector illustrations.\n
